    How it works

    01 / Standardize

    Each feature is centered and divided by its population standard deviation.

    02 / Merge

    Ward linkage joins the pair that minimizes the increase in within cluster squared error.

    03 / Explore

    Choose a cluster count and inspect the standardized scatterplot and full merge sequence.

    Limitations

    This browser adaptation accepts two numeric columns rather than the notebook’s original CSV preprocessing. Missing values and categorical encoding are not supported. Ties can produce a different valid merge order from SciPy. The original dataset is not included. No claims about original results are made.

    FAQ

    Is this live computation?

    Yes. Ward clustering is calculated from the supplied values in your browser.

    Is the example dataset real?

    No. It is synthetic and intended to show how the algorithm behaves.

    Does this use a trained model?

    No. Agglomerative clustering is an unsupervised algorithm executed on the input.
