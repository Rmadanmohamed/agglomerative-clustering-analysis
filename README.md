# Agglomerative Clustering Analysis

## Overview
A clustering notebook using hierarchical clustering, dendrogram visualization, imputation, label encoding, and feature scaling.

## Problem Statement
Unlabeled tabular data can be explored with hierarchical clustering to reveal sample groupings.

## Features
- Data cleaning and imputation
- Categorical label encoding
- Feature scaling
- Dendrogram and agglomerative clustering

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy
- Matplotlib

## Dataset
- /content/data.csv

## Models / Algorithms
- Agglomerative Clustering
- Hierarchical clustering

## Results
The notebook is exploratory and does not contain a final supervised metric.
