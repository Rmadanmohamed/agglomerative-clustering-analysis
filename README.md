# Agglomerative Clustering Analysis

## Overview and problem statement

Explore unlabeled tabular data through hierarchical clustering and visualize groups for exploratory data analysis.

## Technology stack and prerequisites

- Python 3 (exact version not specified); a Python notebook environment is required.
- Declared dependencies in [requirements.txt](requirements.txt): matplotlib, numpy, pandas, scikit-learn, scipy, seaborn. All are unpinned.
- Google Colab or local Jupyter; local Jupyter must be installed separately. No GPU or external service is explicitly required.

## Project structure

- [Notebook](notebooks/agglomerative-clustering-analysis.ipynb) — experiment source.
- [requirements.txt](requirements.txt) — dependency list.
- [LICENSE](LICENSE) — repository license; dataset rights are separate.

## Dataset and preprocessing

`data.csv` at `/content/data.csv`; provenance, license and exact feature names are unspecified. All-empty columns are removed, numeric missing values are mean-imputed, object columns are label-encoded, and columns at zero-based positions 3 and 4 are selected and standardized.

## Model and workflow

SciPy Ward linkage generates a dendrogram. Scikit-learn `AgglomerativeClustering(n_clusters=5, metric='euclidean', linkage='ward')` assigns cluster labels.
